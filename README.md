# dNSC_Thesis_TEOCR

งานวิจัยวิทยานิพนธ์: แก้ข้อความหลัง OCR ภาษาไทยจาก EasyOCR ด้วยการใช้ confidence ชี้จุดที่ควรแก้ (detect-then-correct)

สถานะ: ช่วงสำรวจวรรณกรรมและตั้ง research question (ร่าง ยังไม่ผ่านอาจารย์ที่ปรึกษา)

## โครงสร้าง

| ไฟล์ | เนื้อหา |
|---|---|
| [docs/research-notes.md](docs/research-notes.md) | research question ร่าง, แนวทาง, หลักวิธีวิทยา, เรื่องที่ต้องตัดสินใจ, ลำดับอ่าน |
| [docs/literature-notes.md](docs/literature-notes.md) | บันทึกเปเปอร์ที่อ่านแล้ว (ปัญหา, วิธี, dataset/metric, ผล, ข้อจำกัด, จุดอ่อน) และตารางงานล่าสุด |

## หมายเหตุ

- ไม่เก็บไฟล์ PDF ของเปเปอร์ใน repo (ลิขสิทธิ์/ไลเซนส์ของผู้จัดพิมพ์) ใส่ไว้ในโฟลเดอร์ `papers/` ในเครื่อง ซึ่งถูก ignore แล้ว
- ตัวเลขและข้อสรุปในบันทึกเป็นการอ่านเบื้องต้น ตรวจจากต้นฉบับก่อนอ้างอิง
